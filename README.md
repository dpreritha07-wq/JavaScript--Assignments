# JavaScript Assignments

## 📌 About the Project

This repository contains six practical JavaScript assignments completed to practice and understand the fundamental concepts of JavaScript programming.

## 🎯 Objectives

- Understand JavaScript variables and data types.
- Perform arithmetic operations and handle user input.
- Implement conditional statements.
- Practice loops and flow control.
- Understand functions and scope.
- Work with arrays, objects, and array methods.

## 📚 Assignments

### 1. Variables, Data Types, and Console Operations
Practice variable declarations using `var`, `let`, and `const`, and check data types using `typeof`.

### 2. Operators, Expressions, and Input Handling
Perform arithmetic calculations, accept user input, and calculate a bill with a tip.

### 3. Conditional Logic Implementation
Use `if...else`, `switch`, and the ternary operator to evaluate scores and determine grades.

### 4. Loop Control Structures
Practice `for`, `while`, and `do...while` loops using multiplication tables and loop control statements.

### 5. Function Architecture and Scope
Implement regular functions, arrow functions, default parameters, and block scope.

### 6. Arrays, Objects, and Core Methods
Work with product objects and use `forEach()`, `filter()`, and `map()` to process data.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the HTML files reference the correct JavaScript filenames.
4. Install the Live Server extension if it is not already installed.
5. Right-click the relevant HTML file and select **Open with Live Server**.
6. Open the browser Developer Tools and select the Console tab to view the output.
